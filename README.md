# In Bloom — Fleur storefront

Одностраничная главная с разделами о студии, доставке, оплате, отзывах и контактах. Каталог `/catalog` и страницы букетов `/catalog/[slug]` остаются отдельными. Старые `/about`, `/delivery`, `/contacts` перенаправляют к разделам главной.

## Запуск

Node.js 24: `npm ci`, затем `npm run dev`. Локальную админку открывайте через `http://localhost:3000/admin` с тем же адресом в `SITE_URL` и Google OAuth. Домен пока не выбран, локальная разработка не требует публичного HTTPS.

Проверка сборки: `npm run typecheck`, `npm test`, `npm run build`. Сборка автоматически добавляет изображения, шрифты и static-файлы в standalone. `npm start` запускает этот сервер; можно указать `npm start -- --hostname 127.0.0.1 --port 3001`. Это production-режим: вход в админку требует HTTPS-origin, поэтому для локальной работы с ней используйте `npm run dev`.

Перед публикацией выполните `npm run check:production`: команда проверяет те же обязательные настройки, что и сервер админки, и не печатает секреты. При нынешнем локальном HTTP-адресе она ожидаемо сообщает «Адрес сайта». После выбора домена задайте реальный HTTPS-origin, настройте OAuth и пройдите [проверку развёртывания](docs/hosting/kz-deployment.md).

## Управление букетами

[Новая Google Таблица](https://docs.google.com/spreadsheets/d/1_c3LU0bGnlkpPgSp6WXUTSe0mId_WjArSk4Keg5pK0k/edit) дополнена полным каталогом: 23 букета из Florax и сохранённые позиции из админки. [Инструкция владельцу](docs/catalog/README.md), [однократное подключение](docs/catalog/SETUP.md). Локальное живое подключение выполнено: сервер получает каталог из Google, изменение цены и добавление/скрытие строки проверены без перезагрузки страницы. В `.env.example` перечислены серверные переменные. Без них сайт явно показывает предварительный каталог; при ошибке настроенного Google не выдаёт старые примеры за актуальные цены.

Каталог серверный и доступен без JS на момент запроса. При включённом JS цена, ассортимент и WhatsApp-текст обновляются каждые 5 секунд на видимой вкладке с коротким серверным кэшем. Карточки, поиск, сортировка, бюджет и категории работают с одним источником. Редактор Google Sheets нужен только владельцу; посетителям доступны чтение и обращение в WhatsApp.

## Админка с телефона

`/admin`: вход через разрешённый Google-аккаунт, добавление и редактирование букетов, публикация/скрытие и загрузка фото из галереи/камеры телефона. Товары остаются в текущей Google Таблице, фото хранятся в Cloudinary; отдельная БД не нужна. Без полной настройки редактирование блокируется. [Инструкция подключения и работы](docs/admin/README.md).

Сессии подписаны, запись/загрузка защищены серверной проверкой доступа и Origin. Повтор сохранения использует тот же ID; после неизвестного результата Google приложение перечитывает строку. Первый выпуск рассчитан на один Node-процесс, конкурентное ручное редактирование Sheets не имеет транзакционной гарантии.

Для будущего .kz см. [варианты хостинга, расходы и развёртывание](docs/hosting/kz-deployment.md); Dockerfile/Compose/Caddy подготовлены для установки на VPS. Локальная проверка 29 октября подтвердила чтение Google Sheets и доступность Cloudinary; сохранённый протокол той же даты содержит успешные вход, загрузку фото, изменение и скрытие тестового букета. Это не подтверждает работу на будущем production-домене: там HTTPS, OAuth и полный сценарий нужно проверить отдельно.

Проверка админки: `npm run test:e2e:admin`. Она запускает изолированные локальные окружения с поддельными ключами и подменёнными API-ответами; настоящие таблицы и фото не меняются.

## Границы

Корзина, онлайн-оплата и автоматическое принятие заказа не добавлены. Флорист подтверждает состав, наличие и получение. Раздел «Акции» удалён; старый адрес `/promotions` перенаправляет в каталог. Палитра обновлена по Instagram студии: оливково-зелёный #626B36 и розовый #F89A9F. CSS отвечает за наведение и нажатие, React ViewTransition / Next Link — за переходы, Framer Motion — за однократное появление блоков с нижних углов. При prefers-reduced-motion пространственные анимации отключаются; серверный HTML остаётся читаемым без JavaScript.

Шрифты Simeiz/Gilroy не предоставлены: сохранены замены из согласованного макета. Для первого экрана создано атмосферное изображение через ImageGen: `public/images/hero-inbloom-garden.webp`. Оно иллюстрирует настроение студии и не является фотографией товарной позиции; реальные фотографии каталога сохранены.

Исходные фотографии и сведения о магазине: Florax и 2ГИС, снимок 29.10.2026 для 23 товаров (19 новых фотографий, четыре прежние); лицензии шрифтов в `public/licenses/`. Логотип — неизменённый `public/images/logo.png`. Хостинг и домен не выбраны; локальная сборка не означает публичную публикацию.

## Проверки

`npm test` проверяет цены, видимость, идентификаторы, безопасные фото-ссылки, отказы Google, короткий кэш, обновление данных, отмену/таймаут запросов и полноту настроек админки. `npm run typecheck` и `npm run build` проверяют Next.js/TypeScript.

`npm run test:e2e` проверяет текущую витрину на изолированном предварительном каталоге: адаптивность, меню, FAQ, поиск/фильтры, ссылки, анимации, отказ загрузки и работу без JavaScript. `npm run test:e2e:admin` отдельно проверяет админку. `npm run test:e2e:all` запускает оба набора последовательно. Данные настоящего магазина не являются тестовыми фикстурами и не изменяются. Успешные локальные тесты не заменяют проверку на опубликованном домене.

Мобильный первый экран занимает доступную высоту окна под шапкой. Основные кнопки используют соединённую капсулу и круглую стрелку; декоративная лента In Bloom движется справа налево, не имеет кнопки паузы и останавливается вне экрана, в скрытой вкладке и при prefers-reduced-motion.

Отзывы: короткие цитаты Давида Аряева (25.09.2026) и Асель Бекбосыновой (12.07.2026), рейтинг 5,0 / 160 оценок проверены в живой карточке [2ГИС](https://2gis.kz/astana/firm/70000001105801781/tab/reviews) 28.10.2026. Это вручную обновляемый снимок, не API-синхронизация; на сайте указана дата рейтинга и ссылка на все отзывы. Инициалы обозначают авторов, фотографии товаров не выдаются за фотографии из отзывов.
