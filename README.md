# In Bloom — Fleur storefront

Рабочий Next.js-сайт по утверждённому макету: `/`, `/catalog`, `/catalog/[slug]`, `/promotions`, `/about`, `/delivery`, `/contacts`.

## Запуск

Node.js 24: `npm ci`, затем `npm run dev`. Production-проверка: `npm run typecheck`, `npm test`, `npm run build`.

## Управление букетами

[Новая Google Таблица](https://docs.google.com/spreadsheets/d/1_c3LU0bGnlkpPgSp6WXUTSe0mId_WjArSk4Keg5pK0k/edit) заполнена пятью букетами. [Инструкция владельцу](docs/catalog/README.md), [однократное подключение](docs/catalog/SETUP.md). Локальное живое подключение выполнено: сервер получает каталог из Google, изменение цены и добавление/скрытие строки проверены без перезагрузки страницы. В `.env.example` перечислены серверные переменные. Без них сайт явно показывает предварительный каталог; при ошибке настроенного Google не выдаёт старые примеры за актуальные цены.

Каталог серверный и доступен без JS на момент запроса. При включённом JS цена, ассортимент и WhatsApp-текст обновляются каждые 5 секунд на видимой вкладке с коротким серверным кэшем. Карточки, поиск, сортировка, бюджет и категории работают с одним источником. Редактор Google Sheets нужен только владельцу; посетителям доступны чтение и обращение в WhatsApp.

## Границы

Корзина, онлайн-оплата и автоматическое принятие заказа не добавлены. Флорист подтверждает состав, наличие и получение. Акции без подтверждённых условий не выдуманы. Палитра обновлена по логотипу: зелёный #243E30 и розовый #F89A9F. CSS отвечает за наведение и нажатие, React ViewTransition / Next Link — за переходы, Framer Motion — за однократное появление блоков с нижних углов. При prefers-reduced-motion пространственные анимации отключаются; серверный HTML остаётся читаемым без JavaScript.

Шрифты Simeiz/Gilroy не предоставлены: сохранены замены из согласованного макета. Пионы использованы из визуального референса для предварительного показа; источник финального hero-изображения согласуется перед публичным запуском.

Исходные фотографии и сведения о магазине: Florax и 2ГИС, снимок 28.10.2026 для пяти стартовых товаров; лицензии шрифтов в `public/licenses/`. Логотип — неизменённый `public/images/logo.png`. Хостинг и домен не выбраны; локальная сборка не означает публичную публикацию.

## Проверки

`npm test` проверяет цены, видимость, идентификаторы, безопасные фото-ссылки, отказы Google, короткий кэш и обновление данных. `npm run typecheck` и `npm run build` проверяют Next.js/TypeScript. Старые e2e-сценарии, привязанные к прежнему зелёному лендингу и карусели, требуют переноса на новые маршруты; локальный unit/build успех не означает их успешный прогон или живую проверку Google.
