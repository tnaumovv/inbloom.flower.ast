# Каталог In Bloom — изменить цену за 10 секунд

[Открыть Google Таблицу](https://docs.google.com/spreadsheets/d/1_c3LU0bGnlkpPgSp6WXUTSe0mId_WjArSk4Keg5pK0k/edit)

1. Найдите букет в столбце «Название».
2. Измените число в столбце «Цена», например `15700` на `16000`.
3. Нажмите Enter. Дождитесь отметки Google «Сохранено на Диске».

После однократного подключения сайт проверяет таблицу каждые 5 секунд. Изменение цены занимает несколько секунд и не требует программиста. Обычно новая цена появляется на открытой странице примерно за 5–10 секунд; время Google и сети не гарантируется. При скрытой вкладке обновление возобновляется при возвращении.

## Добавить букет

Добавьте строку, заполните ID, название, цену и фото. Поставьте `TRUE` в «Показывать». Для черновика оставьте это поле пустым или укажите `FALSE`. Дублировать ID нельзя. Категории появляются из заполненных строк, вручную в коде добавлять их не нужно.

| Столбец | Что писать |
|---|---|
| ID | Постоянное уникальное имя латиницей: `pink-cloud`. После публикации лучше не менять: от него зависит ссылка на букет. |
| Название | Название для покупателя. |
| Цена | Положительное целое число в тенге: `15700`. Не пишите «от», «по запросу» или формулу с ошибкой. |
| Фото | Прямая HTTPS-ссылка на доступную фотографию. Вставляйте ссылку как текст, не картинку внутри ячейки. Для пяти исходных фото уже указаны готовые пути. |
| Описание | Необязательное описание до 3000 знаков. |
| Состав | Необязательно; разделяйте позиции знаком `;`. |
| Показывать | `TRUE` — показывать, `FALSE` или пусто — скрыть. |
| Порядок | Число: сначала 1, затем 2 и т. д. Пусто — порядок строк. |
| Категория | Необязательное название категории. |

Скрытие строки и удаление букета убирают его из каталога и отключают его персональное действие заказа на уже открытой странице после следующего обновления. Новый букет получает собственную страницу автоматически. Фото должно открываться по ссылке без входа в аккаунт; ссылки на страницу просмотра файла могут не быть прямыми ссылками на изображение.

## Если каталог не обновился

Проверьте сохранение в Google, ID, цену, фото и столбец «Показывать». Ошибка в активной строке останавливает выдачу каталога: посетитель увидит сообщение с повтором и обращением к флористу, а не незаметно старую цену. Ошибка скрытого черновика не мешает каталогу.

Таблица содержит только публичные данные витрины. Не помещайте туда клиентов, закупочные цены, пароли или внутренние документы. Доступ по ссылке должен оставаться «Читатель»; редактировать могут только владелец и отдельно добавленные редакторы.
