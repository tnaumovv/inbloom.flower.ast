# Каталог In Bloom — изменить цену за 10 секунд

[Открыть Google Таблицу](https://docs.google.com/spreadsheets/d/1_c3LU0bGnlkpPgSp6WXUTSe0mId_WjArSk4Keg5pK0k/edit)

1. Найдите букет в столбце «Название».
2. Измените число в столбце «Цена», например `15700` на `16000`.
3. Нажмите Enter. Дождитесь отметки Google «Сохранено на Диске».

После однократного подключения сайт проверяет таблицу каждые 5 секунд. Изменение цены занимает несколько секунд и не требует программиста. Обычно новая цена появляется на открытой странице примерно за 5–10 секунд; время Google и сети не гарантируется. При скрытой вкладке обновление возобновляется при возвращении.

## Добавить букет

Добавьте строку, заполните ID, название, цену и фото. Поставьте `TRUE` в «Показывать». Для черновика оставьте это поле пустым или укажите `FALSE`. Дублировать ID нельзя. Категории появляются из заполненных строк, вручную в коде добавлять их не нужно.

| Столбец | Что писать |
|---|---|
| ID | Постоянное уникальное имя латиницей: `pink-cloud`. После публикации лучше не менять: от него зависит ссылка на букет. |
| Название | Название для покупателя. |
| Цена | Положительное целое число в тенге: `15700`. Не пишите «от», «по запросу» или формулу с ошибкой. |
| Фото | Прямая HTTPS-ссылка на доступную фотографию. Вставляйте ссылку как текст, не картинку внутри ячейки. Для исходных и перенесённых фотографий уже указаны локальные пути `/images/catalogue/...`. |
| Описание | Необязательное описание до 3000 знаков. |
| Состав | Необязательно; разделяйте позиции знаком `;`. |
| Показывать | `TRUE` — показывать, `FALSE` или пусто — скрыть. |
| Порядок | Число: сначала 1, затем 2 и т. д. Пусто — порядок строк. |
| Категория | Необязательное название категории. |

Скрытие строки и удаление букета убирают его из каталога и отключают его персональное действие заказа на уже открытой странице после следующего обновления. Новый букет получает собственную страницу автоматически. Фото должно открываться по ссылке без входа в аккаунт; ссылки на страницу просмотра файла могут не быть прямыми ссылками на изображение.

## Если каталог не обновился

Проверьте сохранение в Google, ID, цену, фото и столбец «Показывать». Ошибка в активной строке останавливает выдачу каталога: посетитель увидит сообщение с повтором и обращением к флористу, а не незаметно старую цену. Ошибка скрытого черновика не мешает каталогу.

Таблица содержит только публичные данные витрины. Не помещайте туда клиентов, закупочные цены, пароли или внутренние документы. Доступ по ссылке должен оставаться «Читатель»; редактировать могут только владелец и отдельно добавленные редакторы.

## Перенос полного каталога от 29 октября 2026 года

[Проверенный снимок источника](../../src/features/catalog/florax-catalog.json) содержит 23 букета: названия, цены в тенге, состав и источники фотографий. Четыре букета уже присутствуют в таблице — `pink-cloud`, `soft-pink`, `mono-sophie`, `sophie-planter`. Их постоянные ID сохранены. Остальные 19 получают отдельные ID с номером исходного товара: например, `bag-303869`. Одинаковые названия Bag, Dopamine и Mono относятся к разным букетам; артикул добавляется в сообщение заказа WhatsApp.

19 новых фотографий сохранены в проекте как WebP; четыре совпавших изображения используются без изменений. [CSV с 23 исходными букетами](florax-import-2026-10-29.csv) нужен для сверки или подготовки новой таблицы. **Не заменяйте им действующую таблицу:** в ней могут быть скрытые товары, исправленные цены и букеты, созданные через админку.

Для безопасного дополнения существующей таблицы используется Node.js 24 и скрипт из корня проекта:

```sh
node scripts/import-florax-catalog.mjs --dry-run
node scripts/import-florax-catalog.mjs --apply
```

По умолчанию скрипт только показывает план. Он читает настройки из `.env.local`: `GOOGLE_SHEET_ID`, `GOOGLE_SHEETS_API_KEY` и необязательный `GOOGLE_SHEET_RANGE`. Для `--apply` нужны `GOOGLE_SERVICE_ACCOUNT_EMAIL` и `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` с правом редактировать эту таблицу. Значения секретов не выводятся.

Скрипт добавляет только отсутствующие ID через `RAW` и `INSERT_ROWS`, сохраняет все существующие строки целиком, включая их видимость, цены и порядок, затем проверяет результат чтением. Повторный запуск не добавляет дубликаты. При неопределённом ответе Google запись не повторяется вслепую: сначала выполните `--dry-run`. Новые изображения должны присутствовать на сервере вместе с этой версией сайта.

Google Таблица остаётся единственным источником подключённой витрины и админки. Локальный каталог для неподключённого окружения содержит 24 букета: пять прежних и 19 новых. Ошибка Google не подменяет живые данные локальными ценами. Это разовый перенос; дальнейшие изменения выполняются в собственной админке или Google Таблице.
