# In Bloom: интерактивная витрина

Локальный прототип одного блока лендинга. Откройте `dist/index.html` в браузере или запустите из этой папки:

```sh
python3 -m http.server 4173 --directory dist --bind 127.0.0.1
```

Адрес: http://127.0.0.1:4173

Карточки перелистываются свайпом, перетаскиванием мышью, стрелками и клавишами ← / →. Home и End переходят к первому и последнему букетам. Центральный букет увеличивается, приподнимается и слегка поворачивается; наклон также реагирует на курсор. Автоматического перелистывания нет. При `prefers-reduced-motion` объёмное движение и плавная прокрутка отключаются.

Используются нативная прокрутка, CSS Scroll Snap и CSS 3D transforms. Это анимация прозрачных изображений, а не вращаемая на 360° модель букета. Сборка и зависимости не нужны.

Ссылки WhatsApp открывают сообщение с названием и ценой букета; отправляет сообщение сам клиент. Названия и цены взяты из публичного каталога In Bloom при исследовании 18.10.2026. Перед запуском сайта их нужно подтвердить у владельца. Изображения — сгенерированные вырезки на основе публичных фото, для демонстрации дизайна.

Промпт, режим генерации и происхождение изображений: `assets-receipt.json`.
